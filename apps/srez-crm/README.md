# srez CRM — прототип CRM для курса маркетинга

Демо: `/srez-crm/` на сайте. Все данные вымышлены и хранятся только в браузере. Стиль — как у лендинга srez (`/mads/`): чёрный фон, лайм `#D8F83A`, шрифты Unbounded, Inter Tight и JetBrains Mono (лежат рядом со сборкой).

## Что умеет

- **Заявки:** четыре колонки — Новые → Связались → Созвон → Ждём оплату. Закрыть заявку — перетащить вниз на «Оплатил» или «Отказ» (причина обязательна).
- **Созвон-консультация** вместо пробного урока: день и время, «Созвон прошёл» / «Не вышел».
- **Оплата:** тариф «Живой поток» или «Записи», сразу или в рассрочку на 10 платежей. График строится сам, участник попадает в поток.
- **Поток:** группы по 4–5 человек с куратором, участники на записях, прогресс по шести блокам и статус оплаты у каждого.
- **Домашки:** очередь проверки для куратора — «Принять» или «На доработку» с комментарием.
- **Оплаты:** ближайшие платежи, просрочки, журнал. Платёж можно перенести на неделю.
- **Расписание:** 36 занятий по блокам. Ещё есть напоминания (календарь), отчёты и шаблоны сообщений для Telegram.

Роли (переключаются внизу меню):
- администратор — всё;
- менеджер продаж — заявки, оплаты, поток;
- куратор — проверка работ своей группы;
- владелец — цифры.

## Стек и структура

React 19 + TypeScript + Vite + Tailwind CSS 4, иконки lucide-react. Каркас общий с `apps/english-crm`.

```
src/
  domain/   types.ts — заявки, потоки, группы, кураторы, участники, рассрочка, домашки
  data/     store.ts (Repository + LocalRepository), actions.ts, selectors.ts, seed.ts
  app/      каркас, роли и права, поиск, карточки и окна
  screens/  Сегодня, Заявки, Домашки, Поток, Расписание, Напоминания, Оплаты, Отчёты, Настройки
```

**Замена хранилища на API:** нужно реализовать `Repository` (`load / save / clear`), а действия из `data/actions.ts` превратить в запросы к серверу. Экраны при этом не меняются.

Сборка: `npm run build` — результат в `/srez-crm`.
